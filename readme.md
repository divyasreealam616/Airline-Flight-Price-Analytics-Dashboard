# Airline Flight Price and Performance Analytics Dashboard

## Project Overview

This project presents an interactive Power BI dashboard designed to analyze airline flight pricing and identify the factors that influence ticket prices.

The analysis explores airline, route, travel class, number of stops, flight duration, departure time, arrival time, and the number of days remaining before departure.

## Objectives

* Analyze flight prices across different airlines
* Compare ticket prices across travel classes
* Identify expensive and affordable routes
* Analyze the relationship between ticket price and days remaining before departure
* Compare prices based on the number of stops
* Analyze flight duration and its relationship with ticket prices
* Provide an interactive dashboard for exploring airline pricing patterns

## Dataset

The dataset contains flight-level information including:

* Airline
* Flight number
* Source city
* Destination city
* Departure time
* Arrival time
* Number of stops
* Travel class
* Flight duration
* Days left before departure
* Ticket price
